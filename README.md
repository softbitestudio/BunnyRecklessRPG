An interactive, browser-based top-down pixel RPG that acts as a living portfolio, game realm, and secret-driven web exploration experience. Powered by pure HTML5 Canvas and vanilla JavaScript with zero external assets or heavy frameworks.

---

## ✨ Key Features

* 🌲 **Dense Forest & UrbEx Exploration:** Navigate a lush canopy filled with 7 enterable structures. Search for hidden carrots—*"It's not stealing, it's UrbEx!"*
* 🍄 **Trippy Mushroom Switcheroo:** Click interactive mushrooms scattered across the woods to trigger temporary, neon color-palette inversions.
* 🦇 **Saito da Kitsune & Bat Wings:** Track down Saito in the *Abandoned Schoolhouse* to hear tales of urban exploration and receive **Bat Wings**—granting high-speed flight and full map phase-through capabilities.
* 🍻 **Tavern Interior & Carrot Economy:** Step inside the Fluff Coven Tavern to trade looted carrots for unlockable reward coupons (5%, 10%, 15% discount codes) and rare gallery art, or sign the persistent guestbook.
* 💎 **Web Node Integration:**
  * **Projects Cave:** Built around [`txterr.ju.mp`](https://txterr.ju.mp) and app relics.
  * **Pulse Node:** Dedicated link to [`quantum.uwu.ai`](https://quantum.uwu.ai) (*"Tawny keeps her paw on the pulse"*).
  * **Saito's Telegram:** Direct portal to [`t.me/saitodakitsune`](https://t.me/saitodakitsune).
* 👾 **Boss Fight & Minigames:** Battle **The Monstah** in the cave using a timing-based claw reflect mechanic, or navigate the procedural **Neon Maze**.
* 🎨 **Procedural Pixel Art & Web Audio Synth:** All visual sprites, environments, and sound effects are generated dynamically via JavaScript code at runtime.

## 🕹️ Controls

| Key / Input | Action |
| :--- | :--- |
| **`W` `A` `S` `D` / Arrows** | Walk / Fly across the realm |
| **`Space` / `Enter` / Button A** | Interact / Talk / Enter Buildings / Break Pots |
| **`Space` / Tap (In Boss Fight)** | Swing Claw (Reflect glitch-orbs) |
| **`R` / Button B** | Read Zone Logbook / Open Info |
| **`Esc`** | Open Paws Menu (Fast Travel, Fur Customization, Settings) |

---

## 🛠️ Tech Stack & Architecture

* **Engine:** Custom 2D Top-Down Tile & Entity Engine in Vanilla JS.
* **Graphics:** HTML5 Canvas API (Pixel-art rendering, dynamic shadow blending, particle system).
* **Audio:** Web Audio Context Synthesizer (Zero `.mp3` or `.wav` dependencies).
* **Styling:** CSS3 CSS Variables, Glassmorphism UI, Responsive Touch D-Pad for mobile support.
